# Electricity Portfolio Hedging

This repository contains the analysis for the HTW Summer School project
**“Trading and Hedging a Retail Electricity Portfolio.”**

The project develops a simplified retail electricity procurement framework for 2024. It includes:

- construction of a customer load forecast,
- Hourly Price Forward Curve (HPFC) construction,
- futures hedge optimization,
- Day-Ahead shaping,
- imbalance settlement,
- final cost and risk comparison,
- severe-price-event analysis.

## Execution Order

Run the notebooks in the following order:

1. `00_Exhibits.ipynb`
2. `01_HPFC.ipynb`
3. `02_Hedging.ipynb`
4. `03_Costs.ipynb`
5. `04_Advise_Interpret.ipynb`

Later notebooks use outputs generated by earlier notebooks.
